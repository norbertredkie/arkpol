# EU Regulation 561/2006 - Tachograph Exemption for Arkpol

**Date Verified:** 2026-05-13  
**Source:** Wydział ds Tachografów, Ministerstwo Infrastruktury (Polish Ministry of Infrastructure - Tachograph Department)  
**Regulation:** **WE 561/2006** (EU Regulation 561/2006)  
**Specific Article:** **Art. 3, pkt. H** (Article 3, point H)

---

## Key Finding: Arkpol NOT Required to Install Tachographs

### Official Confirmation

The Polish Ministry of Infrastructure **Tachograph Department** has officially confirmed that **Arkpol does NOT need to install tachographs** in company vehicles.

### Legal Basis

**EU Regulation 561/2006** - Harmonisation of certain provisions relating to road transport  
**Article 3, Point H** - Contains the exemption that applies to Arkpol
